# WIN Space

**Team quizzes and interactive activities for shared events.**

WIN Space brings room management, smartphone participation and quiz scoring into one workflow. It is designed to replace paper answer sheets and manual score aggregation while keeping organisers in control of the results.

**[Open WIN Space](https://maskini.github.io/win-space/)**

## Core experience

- **Independent rooms:** organisers manage each activity separately; participants join using a room code.
- **Team quizzes:** a designated team leader submits answers, with automatic scoring for closed questions and manual assessment of written responses.
- **Result review:** moderators review scores before publishing results to participants.
- **Room management:** edit, archive, restore or delete rooms through the organiser workspace.

Additional activity modes include live polls, Guess the Room, Campus Guessr and photo voting.

## Engineering focus

The application combines **TypeScript, React, Tailwind CSS and SQLite**. Development focuses on responsive interfaces, room ownership, participant permissions and consistent scoring across devices.

Local automated tests cover scoring, team permissions, room ownership, result publication, and archive and restore behaviour.

## Project status

Organisers sign in with a one-time email code. Complete event testing across separate devices is ongoing.

This repository contains the public project page. The application source is maintained privately.
